# Guide des membres d'équipe

Vous participez à l'encadrement d'une manifestation. L'application vous indique **où aller**, **quoi faire**, et vous
permet de **prévenir l'organisation** en un geste.

> En cas d'urgence vitale, appelez directement le **15** (SAMU), le **17** (police), le **18** (pompiers) ou le
> **112**. L'application ne prévient pas les secours.

## 1. Activer votre compte

1. L'organisation a créé votre compte et vous a transmis un **lien d'activation** (SMS, messagerie…). Ouvrez-le sur
   votre **téléphone**.
2. Touchez **Se connecter**. Votre équipe s'affiche directement ; si vous êtes dans plusieurs équipes, choisissez-la
   dans *Mes équipes*.
3. Ouvrez **Profil** pour vérifier votre **prénom**, votre **nom** et, si vous le souhaitez, votre **e-mail** et votre
   **téléphone** (pour que l'organisation et votre responsable puissent vous appeler).

Il n'y a **pas de mot de passe** : ce téléphone reste connecté plusieurs jours. Pour vous reconnecter plus tard :

- **par e-mail** : page d'accueil → onglet *Lien de connexion* → *Recevoir un lien par e-mail*. Il faut avoir renseigné
  votre adresse dans votre profil.
- **depuis un autre de vos appareils déjà connecté** : *Profil* → *📱 Connecter un appareil*, puis scannez le QR code ;
- **en demandant un lien** à votre responsable ou à l'organisation.

Votre équipe vous est attribuée par l'organisation : il n'y a rien à rejoindre vous-même.

**Conseil** : ajoutez l'application à l'écran d'accueil. Sur Android, menu ⋮ → *Ajouter à l'écran d'accueil* ; sur
iPhone, bouton Partager → *Sur l'écran d'accueil*.

## 2. L'écran « Mission »

En haut, le nom de votre équipe et l'indicateur **● direct**. Si vous voyez **○ il y a 5 min**, la connexion est
coupée et les informations datent de ce moment-là.

- **Votre point** : son nom, son rang (« Point 1 sur 3 »), ses consignes et son statut.
- **Les grands boutons** changent selon l'étape :
  - **En route** quand vous partez vers le point ;
  - **Arrivé** une fois sur place ;
  - **Terminé** quand l'organisation vous libère ;
  - **Relève nécessaire** si vous devez être remplacé.
- **🆘 Aide** : prévient immédiatement l'organisation que vous avez besoin d'aide à votre point.
- **Signaler un incident** : ouvre l'onglet *Incidents*.
- **🧭 Aller au point suivant** : ouvre votre application de navigation (Google Maps, Waze, Plans…) vers le point
  suivant de votre liste. Vérifiez sur place que le passage est possible et sûr.
- **La carte** montre le parcours et vos points. Pour la déplacer, utilisez **deux doigts** ; un doigt fait défiler la
  page.
- **Tête du cortège à 350 m de ce point** : vous savez quand il arrive.
- **« La fermeture du cortège a dépassé ce point »** : vous pourrez quitter le point **sur instruction** de
  l'organisation, puis toucher *Terminé*.
- Sous le nom de l'équipe : le **📞 téléphone de votre responsable**, s'il l'a renseigné.
- Sous la carte : le **partage de position** et **OwnTracks**, sur une ligne chacun (voir plus bas).
- En bas : les **consignes** générales et d'équipe, et les **points restants**, avec leur distance sur le parcours
  depuis le point en cours (« +0,35 km ») ; touchez un nom pour l'afficher. Le lien **⬇ GPX des points de l'équipe**
  s'ouvre dans OsmAnd, Organic Maps ou un GPS.

## 3. Messages

- Un **bandeau rouge** signale un message urgent de l'organisation : touchez-le pour le lire.
- L'onglet **Messages** affiche les annonces à tous et les échanges avec votre équipe. Les messages sont marqués comme
  lus quand vous ouvrez l'onglet, et l'organisation le voit.
- Vous pouvez **répondre** : votre message est lu par votre équipe et par l'organisation.

## 4. Incidents

- Onglet **Incidents** → choisissez la **nature** (sécurité, santé, circulation, matériel…), décrivez en quelques mots,
  puis **Envoyer le signalement**.
- Cochez **Joindre ma position actuelle** si l'incident n'est pas exactement à votre point.
- Vous voyez ensuite son suivi : *Ouvert*, *Pris en charge par…*, *Résolu*.

## 5. Selon votre type d'équipe

- **Équipe volante** : vous n'avez pas de point fixe. Les **demandes d'aide (🆘)** en cours s'affichent en rouge en
  haut de l'écran *Mission*, avec **🧭 Rejoindre le lieu**, qui ouvre votre application GPS vers la position envoyée
  ou, à défaut, vers le point de l'équipe qui a demandé de l'aide. Tous les incidents de la manifestation sont dans
  *Incidents* : touchez **J'y vais** pour indiquer que vous intervenez, et **Résolu** une fois réglé.
- **Ouverture** : vous marchez en tête. Si vous partagez votre position, la tête du cortège avance **toute seule**.
  Sinon, touchez régulièrement **📍 La tête est ici**, ou indiquez les km parcourus.
- **Fermeture** : vous fermez la marche. Même principe : votre position partagée fait avancer la queue, sinon touchez
  régulièrement **📍 La queue est ici**. Les équipes dont le point est
  dépassé en sont informées.

## 6. Partager sa position (facultatif)

Si l'organisation l'a autorisé pour la manifestation, le bloc **Partager ma position** apparaît dans l'onglet
*Mission*. Sinon, il n'est pas affiché : demandez à l'organisation de l'activer.

- C'est **votre choix** : vous pouvez l'arrêter à tout moment (*Arrêter*).
- L'organisation voit seulement **votre dernière position**, sans historique. Elle est effacée quand vous arrêtez.
- **Arrivée automatique** : à moins de 30 m de votre point, vous passez « en position » sans rien toucher.
- **Ouverture et fermeture** : votre position fait avancer la tête ou la queue du cortège (seule la distance sur le
  parcours est retenue, sans votre nom).
- Le partage ne fonctionne que **tant que l'application est ouverte à l'écran**. L'écran reste allumé pendant le partage.

**Suivi écran éteint avec OwnTracks** (facultatif) :

1. Installez l'application gratuite **OwnTracks** : Google Play ou F-Droid sur Android, App Store sur iPhone.
2. Dans la vue terrain, bloc *Suivi écran éteint* → **Configurer** → **Créer mon lien de configuration**.
3. Touchez **Ouvrir OwnTracks avec la configuration** : l'application se règle seule.
4. Autorisez la localisation **« Toujours »**, et désactivez l'économie de batterie pour OwnTracks.

Ce lien est **personnel** : ne le partagez pas. Le suivi consomme beaucoup de batterie, prévoyez une batterie externe.
Il s'arrête tout seul après la manifestation, et vous pourrez alors désinstaller OwnTracks.

## 7. Questions fréquentes

- **J'ai changé de téléphone ou effacé mes données** : recevez un lien par e-mail (si votre adresse est dans votre
  profil), ou demandez un **lien de connexion** à votre responsable ou à l'organisation.
- **« Ce lien a déjà servi »** : un lien ne sert qu'une fois. Si c'était vous, ouvrez simplement l'application : vous
  êtes toujours connecté. Sinon, demandez-en un nouveau.
- **Le bouton ne répond pas, « action impossible »** : vérifiez la connexion (indicateur ○), puis réessayez. En cas de
  doute, appelez votre responsable.
- **« Vous n'êtes plus membre d'aucune équipe »** : l'organisation vous a retiré de l'équipe. Contactez-la.
- **Je n'ai pas encore d'équipe** : la page *Mes équipes* l'indique. Elle se remplit dès que l'organisation vous ajoute.
- **Responsable d'équipe** : si l'organisation le permet, vous ajoutez et retirez des membres depuis la vue terrain
  (*Gérer les membres de l'équipe*), et vous pouvez leur envoyer un lien de connexion.

## 8. Vos données

L'application conserve :

- votre **prénom**, votre **nom**, votre **e-mail** et votre **téléphone** si vous les avez indiqués, et vos équipes ;
- vos actions sur les missions (statuts, incidents, messages) ;
- si vous la partagez, **votre dernière position seulement**.

Si l'organisation a fixé une **date d'expiration** à votre compte (indiquée dans votre profil), il est **supprimé
automatiquement** à cette date. Pour toute question, adressez-vous à l'organisation.
