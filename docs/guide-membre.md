# Guide des membres d'équipe

Vous participez à l'encadrement d'une manifestation. L'application vous indique **où aller**, **quoi faire**, et vous
permet de **prévenir l'organisation** en un geste.

> En cas d'urgence vitale, appelez directement le **15** (SAMU), le **17** (police), le **18** (pompiers) ou le
> **112**. L'application ne prévient pas les secours.

## 1. Rejoindre votre équipe

1. Scannez le **QR code** de votre équipe avec l'appareil photo du téléphone, ou ouvrez le **lien** reçu.
2. Indiquez votre **prénom ou un pseudonyme**, puis touchez **Rejoindre l'équipe**.
3. Si l'équipe demande une validation, patientez : la page se met à jour toute seule dès qu'un responsable a accepté.

Il n'y a **ni compte ni mot de passe** : ce téléphone reste connecté pendant la manifestation.

**Conseil** : ajoutez l'application à l'écran d'accueil. Sur Android, menu ⋮ → *Ajouter à l'écran d'accueil* ; sur
iPhone, bouton Partager → *Sur l'écran d'accueil*.

## 2. L'écran « Mission »

En haut, le nom de votre équipe et l'indicateur **● direct**. Si vous voyez **○ il y a 5 min**, la connexion est
coupée et les informations datent de ce moment-là.

- **Votre point** : son nom, son rang (« Point 1 sur 3 »), ses consignes et son statut.
- **Les grands boutons** changent selon l'étape :
  - **En route** quand vous partez vers le point ;
  - **Arrivé** une fois sur place ;
  - **Terminé** quand l'organisation vous libère ;
  - **Relève nécessaire** si vous devez être remplacé.
- **🆘 Aide** : prévient immédiatement l'organisation que vous avez besoin d'aide à votre point.
- **Signaler un incident** : ouvre l'onglet *Incidents*.
- **🧭 GPS** : ouvre votre application de navigation (Google Maps, Waze, Plans…) vers le point en cours ou le point
  suivant.
- **La carte** montre le parcours, vos points et, si vous touchez **📍 Ma position**, l'endroit où vous êtes. Pour
  déplacer la carte, utilisez **deux doigts** ; un doigt fait défiler la page.
- **Itinéraire à pied** : trajet indicatif vers le point. Vérifiez sur place que le passage est possible et sûr.
- **Tête du cortège à 350 m de ce point** : vous savez quand il arrive.
- **« La fermeture du cortège a dépassé ce point »** : vous pourrez quitter le point **sur instruction** de
  l'organisation, puis toucher *Terminé*.
- En bas : les **consignes** générales et d'équipe, et la liste de **toutes les missions**.

## 3. Messages

- Un **bandeau rouge** signale un message urgent de l'organisation : touchez-le pour le lire.
- L'onglet **Messages** affiche les annonces à tous et les échanges avec votre équipe. Les messages sont marqués comme
  lus quand vous ouvrez l'onglet, et l'organisation le voit.
- Vous pouvez **répondre** : votre message est lu par votre équipe et par l'organisation.

## 4. Incidents

- Onglet **Incidents** → choisissez la **nature** (sécurité, santé, circulation, matériel…), décrivez en quelques mots,
  puis **Envoyer le signalement**.
- Cochez **Joindre ma position actuelle** si l'incident n'est pas exactement à votre point.
- Vous voyez ensuite son suivi : *Ouvert*, *Pris en charge par…*, *Résolu*.

## 5. Selon votre type d'équipe

- **Équipe volante** : vous n'avez pas de point fixe. Les incidents de toute la manifestation s'affichent dans
  *Incidents*. Touchez **J'y vais** pour indiquer que vous intervenez, **🧭 GPS** pour vous y rendre, et **Résolu** une
  fois réglé.
- **Ouverture** : vous marchez en tête. Touchez régulièrement **📍 La tête est ici**, ou indiquez les km parcourus.
- **Fermeture** : vous fermez la marche. Touchez régulièrement **📍 La queue est ici**. Les équipes dont le point est
  dépassé en sont informées.

## 6. Partager sa position (facultatif)

Si l'organisation l'a autorisé, le bloc **Partager ma position** apparaît.

- C'est **votre choix** : vous pouvez l'arrêter à tout moment (*Arrêter*).
- L'organisation voit seulement **votre dernière position**, sans historique. Elle est effacée quand vous arrêtez.
- **Arrivée automatique** : à moins de 30 m de votre point, vous passez « en position » sans rien toucher.
- Le partage ne fonctionne que **tant que l'application est ouverte à l'écran**. L'écran reste allumé pendant le partage.

**Suivi écran éteint avec OwnTracks** (facultatif) :

1. Installez l'application gratuite **OwnTracks** : Google Play ou F-Droid sur Android, App Store sur iPhone.
2. Dans la vue terrain, bloc *Suivi écran éteint* → **Configurer** → **Créer mon lien de configuration**.
3. Touchez **Ouvrir OwnTracks avec la configuration** : l'application se règle seule.
4. Autorisez la localisation **« Toujours »**, et désactivez l'économie de batterie pour OwnTracks.

Ce lien est **personnel** : ne le partagez pas. Le suivi consomme beaucoup de batterie, prévoyez une batterie externe.
Il s'arrête tout seul après la manifestation, et vous pourrez alors désinstaller OwnTracks.

## 7. Questions fréquentes

- **J'ai changé de téléphone ou effacé mes données** : demandez un **lien de récupération** à votre responsable ou à
  l'organisation. L'ancien appareil sera déconnecté.
- **« Ce lien a déjà été utilisé »** : un lien individuel ne sert qu'une fois. Si c'était vous, ouvrez simplement
  l'application : vous êtes toujours connecté.
- **Le bouton ne répond pas, « action impossible »** : vérifiez la connexion (indicateur ○), puis réessayez. En cas de
  doute, appelez votre responsable.
- **« Vous n'êtes plus membre d'aucune équipe »** : l'organisation vous a retiré de l'équipe. Contactez-la.
- **Je veux me connecter avec un compte d'organisation sur ce téléphone** : bas de la page, *Se connecter avec un compte
  d'organisation*. L'accès participant sur ce téléphone sera fermé.

## 8. Vos données

L'application conserve :

- votre **pseudonyme** et votre équipe ;
- vos actions sur les missions (statuts, incidents, messages) ;
- si vous la partagez, **votre dernière position seulement**.

Votre accès s'arrête automatiquement après la manifestation. Pour toute question, adressez-vous à l'organisation.
